# 고깃집 키오스크 — 테이블오더 · 카운터 키오스크 (goki-kiosk-restaurant)

갈비 · 고깃집 기준으로 설계한 **테이블오더 + 카운터 키오스크** 디자인안과 화면 명세입니다.
이전 [tablet-kiosk-restaurant](https://github.com/DevOps0906/tablet-kiosk-restaurant)(카운터 키오스크만)를 대신하며, 사장님이 세팅에서 **운영 방식 3가지** 중 하나를 고릅니다.

| 운영 방식 | 주문 | 결제 | 잘 맞는 매장 |
|---|---|---|---|
| ① 카운터 키오스크 | 입구 · 카운터 1~2대 | 주문할 때 (카드 단말) | 국밥 · 백반 · 분식 |
| **② 테이블오더 · 나갈 때 결제** | 테이블마다 태블릿 | 나갈 때 카운터에서 | **고깃집 · 주점 (기본값)** |
| ③ 테이블오더 · 주문할 때 결제 | 테이블마다 태블릿 | 주문할 때 휴대폰 간편결제 | 회전 빠른 식당 |

- 주문은 어느 기기에서 하든 **테이블 번호의 "열린 계산서"**에 쌓이고, 결제는 운영 방식에 맞는 곳(키오스크 · 카운터 · 휴대폰)에서 합니다.
- 메뉴 · 쿠폰 · 더치페이 · 주방 출력은 세 방식이 같은 기능을 씁니다. 다른 것은 "결제를 언제 · 어디서 하느냐"뿐입니다.
- 화면 48장: 구조도 · 흐름도 4 · 테이블 태블릿 7 · 선불 · 옵션 3 · 카운터 정산 4 · 사장님 세팅 8 · 카운터 키오스크 14 · 기획 참고 2 · 쿠폰 6

### PC에서 개발 시작하기

1. **폴더 하나에 core 와 이 저장소를 나란히 클론**합니다. 이 저장소를 core **안에** 클론하지 않습니다 (저장소 안의 저장소 → git 꼬임).

   ```
   kiosk/
   ├── tablet-kiosk-core/          ← 실제 코드 · 멀티에이전트 팀 (여기서 Claude Code 실행)
   └── goki-kiosk-restaurant/      ← 이 저장소 (고깃집 · 식당 설계서)
   ```

   ```bash
   mkdir kiosk && cd kiosk
   git clone https://github.com/DevOps0906/tablet-kiosk-core
   git clone https://github.com/DevOps0906/goki-kiosk-restaurant
   ```

2. **VS Code로 `kiosk/` 폴더를 엽니다.** (Android Studio는 SDK · 에뮬레이터용으로 설치만)
3. **VS Code 터미널에서 core 를 기준으로 Claude Code 를 실행**하고 이 저장소를 함께 엽니다.

   ```bash
   cd tablet-kiosk-core
   claude --add-dir ../goki-kiosk-restaurant
   ```

4. Claude Code 안에서 처음 한 번 `/agent-check`로 팀을 확인하고, `/next-task`로 진행합니다.

## 핵심 기능

### 테이블오더 (② ③)
- **테이블 번호 고정**: 태블릿마다 테이블 번호를 지정(세팅 4-3). 대기 화면에 "12번 테이블"을 크게 표시
- **추가 주문 누적**: 주문할 때마다 1차 · 2차 · 3차로 계산서에 쌓이고, 손님은 "우리 테이블 주문 내역"에서 차수별 금액 · 주방 상태 · 지금까지 합계를 봄
- **주문 확인 모달**: "지금까지 드신 금액 + 이번 주문 = 합계"를 보여 주고 주방으로 보냄. 버튼 중복 탭에도 주문은 1건
- **고깃집 규칙**: 첫 고기 주문은 최소 2인분, 추가 주문은 1인분부터. 주류 19세 안내 · `19` 배지
- **직원 호출**: 불판 교체 · 숯 · 불 세기 · 물 · 앞치마 · 가위 · 집게 · 물티슈 · 반찬 리필 · 계산 요청 + 직접 쓰기 → 카운터 현황판 · 서빙 알림 (출력 안 함)
- **③ 휴대폰 간편결제**: 주문할 때 QR로 토스페이 · 네이버페이 · 카카오페이 · 앱카드 결제 → 승인 후 주방 전송. 휴대폰 결제가 어려우면 "나갈 때 카운터에서 결제"

### 카운터 정산
- **테이블 현황판**: 빈 테이블 · 식사 중 · 호출 · 계산 요청을 색으로 구분, 인원 · 경과 시간 · 현재 금액, 오른쪽 호출 목록 `처리`
- **테이블 계산서**: 차수별 줄 목록 · 취소(사유) · 쿠폰 → 받을 금액 → 전체결제 · 더치페이 · 현금 · 계좌이체
- **테이블 이동 · 합석**: 빈 테이블로 이동, 식사 중 테이블과 계산서 합치기
- **결제 완료 → 테이블 비움**: 테이블 태블릿이 대기 화면으로 돌아감
- **주방 주문서**: 테이블 번호를 가장 크게, 첫 주문 / **추가**(검은 바탕) / 선불 / 미결제 표시

### 카운터 키오스크 (①)
- 매장 / 포장 → 메뉴 → 주문 확인 → 결제(전체결제 · 더치페이 · 쿠폰) → 주방 출력 · 호출번호 (이전 갈비식당 설계 그대로)
- **옵션: 나갈 때 결제** — 주문 확인 다음에 테이블 번호 입력 → 결제 없이 계산서에 쌓임

### 사장님 세팅 (갤럭시탭)
사장님 시작 → 매장 정보 → **2-2 운영 방식** → 메뉴 등록 → 기기 연결 → **4-2 테이블 배치 · 태블릿 연결 QR** → **4-3 태블릿 역할 지정(카운터 · 테이블 번호 · 입구 키오스크)** → 키오스크 모드

### 쿠폰
- 사장님 반응형 대시보드에서 발행(시리얼 · 바코드 · QR · 영수증 인쇄), 손님은 시리얼 12자리 입력 또는 바코드 스캔
- ① 키오스크 결제 화면 / ② **카운터 계산서**에서 적용. 더치페이는 할인 후 금액을 나눔 (core D4 안 A)

| 카운터 | `ct-01` 현황판 · `ct-02` 계산서 · `ct-03` 이동 · 합석 · `ct-04` 주방 주문서 |
| 세팅 | `set-01` ~ `set-05` + `set-02b` 운영 방식 · `set-04b` 테이블 배치 · `set-04c` 태블릿 역할 |
| ① 카운터 키오스크 | 갤럭시탭 `sw-00` ~ `sw-05` 7장 · 스탠드 `00` ~ `05` 7장 |
| 쿠폰 | 대시보드 · 발행 (반응형) · 시리얼 입력 · 바코드 스캔 (스탠드 · 갤럭시탭) |
