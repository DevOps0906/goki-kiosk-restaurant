# 01 식당 업무 규칙

> 코드 위치: `tablet-kiosk-core/apps/kiosk/lib/verticals/restaurant/`. 확장 지점 정의는 core `docs/08-vertical-module.md`.
> 운영 방식(테이블 · 계산서 · 호출)은 업종 규칙이 아니라 core 공통 기능입니다 → `docs/03-operation-modes.md`.

## 업무 규칙

### 1. 인분 단위 주문

- 고기 메뉴는 수량 대신 **인분**으로 표시 (`돼지갈비 3인분`)
- 최소 인분(기본 2인분)
  - ① 카운터 키오스크: 장바구니에서 미만이면 안내하고 결제 진행 불가
  - ② ③ 테이블오더: **그 테이블의 첫 고기 주문에만** 적용, 추가 주문은 1인분부터 (`추가 고기 사리` 메뉴 또는 같은 메뉴 1인분)

### 2. 주류 · 음료

- 분류 이름 `주류 · 음료`, 분류 상단 배너: **"주류는 만 19세 이상만 주문 가능 · 가져다 드릴 때 직원이 신분증을 확인해요"**
- 주류 메뉴 카드에 `19` 배지
- 주류를 담으면 주문서에 `★주류 · 신분증 확인★` 줄 인쇄
- 키오스크 · 테이블 태블릿에서 나이 인증은 하지 않음 (직원 확인 방식)

### 3. 식사 메뉴

- 된장찌개는 고기 주문이 있을 때만 담을 수 있음 (`requires_meat`) — 테이블오더는 **계산서 전체**에 고기 주문이 있으면 허용
- 물냉면 등 식사는 주방 메모 "고기 후 제공" 표시 가능

### 4. 더치페이

- 방식: N등분 · 메뉴별(인분) · 금액
- **메뉴별**: 고기는 1인분 단위로 쪼개 결제자에게 배정 (`돼지갈비 1인분 · 5인분 중 2번째`)
- 식사 · 음료는 1개(그릇 · 병) 단위로 배정
- ② 에서는 카운터 계산서(1~N차 전체)를 대상으로 나눔

### 5. 주방 주문서 (`ct-04-slips`)

- ① 맨 위 `A-017 매장` (2배 크기)
- ② ③ 맨 위 **`테이블 12`** (2배 크기) + 첫 주문 / **추가**(검은 바탕) / 선불 표시, 아래 `N차 · 누적 금액`
- 고기 · 식사 · 찌개 분류(`kitchen_group`)별로 나눠 출력 가능 (주방 프린터 분류 설정)
- 고기는 인분으로 표기

### 6. 직원 호출 항목 (식당)

`불판 교체` · `숯 · 불 세기` · `물` · `앞치마` · `가위 · 집게` · `물티슈` · `반찬 리필` · `계산 요청` + 직접 쓰기

## 확장 지점 구현

| 확장 지점 | 식당 구현 |
|---|---|
| `theme` | 제이드 그린 테마 |
| `preset` | 고기 · 식사 · 찌개 · 탕 · 사이드 · 주류 · 음료 분류 + 예시 메뉴, **운영 방식 기본값 `table_postpaid`** |
| `labels` | `호출번호`, 완료 문구, **직원 호출 항목 목록** (위 6장) |
| `menuCardDecorator` | 주류 `19` 배지, 인분 표기, 인기 배지 |
| `categoryBanner` | 주류 · 음료 분류의 19세 안내 |
| `itemConfigurator` | 고기: 인분 수 선택 (첫 주문이면 최소 인분 기본값) |
| `cartRules` | 최소 인분(첫 고기 주문), `requires_meat`(계산서 기준) |
| `splitOptions` | 메뉴별 분할에서 인분 단위 쪼개기 |
| `printBlocks.kitchen` | 분류별 분할, 주류 신분증 확인 줄 |
| `doneScreenExtras` | ① 호출번호 안내 |
| `setupExtras` | 호출번호 시작값, 고기 최소 인분, 주방 프린터 분류 매핑 |

테이블 번호 · 추가 표시 · 계산서 화면은 core 공통(운영 방식)이 그립니다. 업종 모듈은 위 표만 채웁니다.

## 데이터 키 (`vertical_attrs` · `vertical_data`)

| 위치 | 타입 | 뜻 |
|---|---|---|
| `menu_items.vertical_attrs.portion_unit` | string | 표시용 단위 (`1인분 250g`) |
| `menu_items.vertical_attrs.min_portions` | int | 첫 고기 주문 최소 인분 (기본 2) |
| `menu_items.vertical_attrs.is_alcohol` | bool | 주류 여부 → 19 배지, 안내 |
| `menu_items.vertical_attrs.requires_meat` | bool | 고기 주문이 있을 때만 담기 (된장찌개) |
| `menu_items.vertical_attrs.is_meat` | bool | 최소 인분 · `requires_meat` 판정 대상 |
| `order_items.kitchen_group` | string | 주방 출력 분류 (고기 · 식사 · 찌개) |

운영 방식 데이터(테이블 · 계산서 · 호출)는 업종 키가 아니라 core 테이블입니다 (core `docs/07` 7장).
새 키를 추가하면 이 표를 먼저 고칩니다.
