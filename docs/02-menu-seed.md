# 02 예시 메뉴 · 시드 데이터

> core `supabase/seed.sql`과 업종 `preset`의 기준입니다. 금액은 디자인과 같아야 합니다.
> 고기 메뉴(소갈비 · 양념 LA갈비 · 돼지 생갈비 · 육회 포함)는 모두 `is_meat: true`, `kitchen_group: "고기"`입니다.

## 예시 쿠폰 (대시보드 예시 데이터)

| 쿠폰 | 혜택 | 발행 방식 | 수량 |
|---|---|---|---|
| 첫 방문 감사 5,000원 할인 | 금액 할인 5,000원 · 5만원 이상 | 시리얼 · 바코드 | 200 |
| 첫 방문 10% | % 할인 10% · 매장 · 계산서 적용 (카운터) | 시리얼 · 바코드 | 100 |
| 평일 점심 공깃밥 무료 | 메뉴 무료 (공깃밥 1공기) | 영수증 하단 인쇄 | 300 |
| 단골 소주 1병 무료 | 메뉴 무료 (소주 1병, 성인 확인) | 문자 발송 | 80 |
| 포장 10% 할인 | % 할인 10% · 포장만 | 시리얼 | 100 |

예시 시리얼: `GB24-7KQ9-M2XD` → `첫 방문 감사 5,000원 할인`
