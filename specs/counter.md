# 카운터 정산 명세 — 테이블 현황 · 계산서 · 결제

> 카운터에 둔 갤럭시탭(가로 1280×800, 역할 `카운터`). 카드 단말 · 영수증/주방 프린터가 이 태블릿에 연결됩니다.
> ② ③ 매장에서 씁니다. 규칙의 정본은 `docs/03-operation-modes.md`, 결제 흐름은 core `docs/04`.
> 상단 공통: `카운터` 배지 · 가게 이름 · 탭(테이블 · 주문 목록 · 호출 · 오늘 매출) · 식사 중 / 빈 테이블 수 · `호출 N`.

## 1. 테이블 현황판

- 디자인: [`ct-01-board`](../screenshots/ct-01-board.png)

**구성**

- 구역 탭(홀 · 룸 · 테라스), 테이블 카드 4열: 번호 · 상태 배지 · 인원 · 경과 시간 · 현재 금액 · 호출 내용
- 상태 색: 빈 테이블(흰 점선) · 식사 중(초록) · 호출(노랑) · 계산 요청(파랑) — `docs/03` 2장
- 오른쪽 **호출 · 요청** 목록: 테이블 번호 · 내용 · 경과 · `처리`
- 아래: 오늘 결제 완료 금액, 식사 중 미결제 합계

**규칙**

- 테이블 카드를 누르면 계산서(`ct-02-bill`)
- 호출 · 새 주문은 소리 + 카드 테두리 깜빡임 (사장님 설정으로 끔)
- 실시간: 테이블 태블릿 주문 후 2초 안에 금액 반영

## 2. 테이블 계산서

- 디자인: [`ct-02-bill`](../screenshots/ct-02-bill.png)

**구성**

- 머리: `12 번 테이블 계산서` · 인원 · 착석 시각 · 경과, `메뉴 추가`(카운터에서 대신 주문)
- 줄 목록: 차수 · 시각 · 메뉴 · 수량 · 금액 · `취소`
- 아래: `테이블 이동` · `합석` · `계산서 출력` · `주문 기록`
- 오른쪽: 주문 합계, 쿠폰 할인, **받을 금액**, `전체 결제`, `더치페이`, `쿠폰`, `현금`, `계좌이체`

**규칙**

- `취소`는 사장님 PIN 또는 직원 권한 필요, 사유 선택(손님 변경 · 주방 품절 · 잘못 주문) → 주방에 `취소` 출력
- `전체 결제` → core 결제 흐름(카드 단말 승인, 멱등 키) → 영수증 출력 → 계산서 닫기 → 테이블 태블릿 대기 화면
- `더치페이` → core 더치페이 화면(① `sw-04-dutch`와 같은 컴포넌트), 대상 = 받을 금액
- `쿠폰` → 시리얼 입력 / 바코드 스캔(① 쿠폰 화면과 같은 컴포넌트), 계산서에 적용
- `현금` · `계좌이체` → 받은 금액 입력 → 결제 기록만 (카드 승인 없음)
- `계산서 출력` → 결제 전 확인용 계산서 (영수증 아님)
- 결제 중 새 주문이 들어오면 상단 경고 "결제 중 새 주문 있음 (+38,000원)" → 결제 완료 후 남은 금액으로 이어서

## 3. 테이블 이동 · 합석

- 디자인: [`ct-03-move`](../screenshots/ct-03-move.png)
- 탭: `자리 이동` / `합석 (계산서 합치기)`
- 이동: 빈 테이블만 선택 가능, `12번 → 9번 이동`
- 합석: 식사 중 테이블만 선택 가능, "12번과 4번 계산서를 합칠까요?"
- 규칙은 `docs/03` 5장

## 4. 주방 주문서

- 디자인: [`ct-04-slips`](../screenshots/ct-04-slips.png)
- 테이블 번호를 가장 크게, `첫 주문` / `추가`(검은 바탕) / `선불`, 아래 `N차 · 누적 금액` · 시각
- 직원 호출은 출력하지 않음 (설정으로 켤 수 있음)
- 업종 규칙(분류별 분할, 주류 신분증 줄)은 `docs/01` 5장

## 수용 시나리오

- [ ] 현황판에서 12번(104,000원) 선택 → 계산서에 1~3차 9줄, 합계 104,000원
- [ ] 쿠폰 `첫 방문 10%` 적용 → 받을 금액 93,600원 → 전체 결제(가짜 카드 단말 승인) → 영수증 → 12번 빈 테이블 · 태블릿 대기 화면
- [ ] 더치페이 N등분 4명 93,600원 → 23,400원 × 4
- [ ] 3차 소주 1병 취소(사유: 잘못 주문) → 합계 99,000원, 주방에 취소 출력, 손님 내역에 "취소됨"
- [ ] 12번 → 9번 이동 → 9번에 계산서, 12번 빈 테이블, 두 태블릿 화면 즉시 변경
- [ ] 4번과 합석 → 하나의 계산서, 차수 시간순 정렬
- [ ] 결제 중 12번 태블릿에서 추가 주문 → 경고 표시 → 첫 결제 후 남은 금액만 결제
- [ ] 호출 목록 `처리` → 현황판 색 원래대로, 손님 태블릿 `처리됨`
- [ ] 현금 결제 → 결제 기록 남고 카드 단말 호출 없음
