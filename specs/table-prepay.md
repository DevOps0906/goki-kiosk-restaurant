# 테이블오더 명세 — ③ 주문할 때 결제 (휴대폰 간편결제)

> 2순위 기능입니다. **PG · 간편결제 계약이 정해져야 개발합니다** (core `docs/00` D9).
> 대기 · 메뉴 · 주류 · 내역 · 직원 호출 화면은 ②와 같고(`specs/table-order.md`), 상단 배지가 파랑 · 안내 문구가 "주문할 때 휴대폰으로 결제"로 바뀝니다.

## 1. 메뉴 · 이번 주문

- ②와 같음. 오른쪽 패널 안내 "주문할 때 휴대폰으로 결제해요. 결제가 끝나면 주방으로 가요.", 버튼 `결제하고 주문 ›`(파랑)

## 2. 휴대폰 간편결제

- 디자인: [`tp-03-pay`](../screenshots/tp-03-pay.png)

**구성**

- 결제 QR(이 주문 전용, 5분 유효 · 남은 시간 표시), "휴대폰 카메라로 QR을 찍어 결제해 주세요"
- 지원 수단 표시: 토스페이 · 네이버페이 · 카카오페이 · 앱카드 (계약한 PG가 지원하는 것만)
- 오른쪽: 결제할 주문 · 결제 금액
- 안내 "휴대폰 결제가 어려우세요? 주문은 지금 보내고 나가실 때 카운터에서 결제할 수 있어요" + `나갈 때 카운터에서 결제` (사장님 설정으로 숨김 가능), `주문 수정`

**규칙**

- 결제 승인 알림(PG 웹훅 → 서버)을 받기 전에는 주방으로 보내지 않음
- QR 시간이 지나면 새 QR. 같은 주문에 대한 결제는 한 번만 승인 (PG 주문번호 = 멱등 키)
- `나갈 때 카운터에서 결제` → 주문 즉시 주방 전송, 주문서 · 현황판에 `미결제` 표시, 계산서에 미결제 금액으로 쌓임
- 쿠폰 · 더치페이는 이 화면에서 지원하지 않음 → 필요하면 `나갈 때 카운터에서 결제`

## 3. 결제 완료

- 디자인: [`tp-04-done`](../screenshots/tp-04-done.png)
- "결제 완료 · 주방에 주문을 보냈어요", 차수별 결제 상태, **나갈 때 결제할 금액**(미결제 합계), `추가 주문하기`, `직원 호출`
- 미결제 0원이면 손님은 그냥 나가도 됨. 카운터에서 테이블 `비우기`로 계산서 닫기

## 수용 시나리오

- [ ] 7번 태블릿: 돼지갈비 2인분 · 맥주 → `결제하고 주문` → QR → 테스트 PG 승인 → 주방 주문서 `테이블 7 · 선불` 출력
- [ ] QR 5분 경과 → 새 QR, 이전 QR로는 결제 안 됨
- [ ] 같은 주문 결제 승인 알림이 두 번 와도 결제 · 주문은 1건
- [ ] `나갈 때 카운터에서 결제` → 주방 출력 + 현황판 `미결제` → 카운터에서 그 금액만 결제
- [ ] 미결제 0원 테이블을 카운터에서 `비우기` → 대기 화면
