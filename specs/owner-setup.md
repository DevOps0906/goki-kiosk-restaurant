# 사장님 세팅 명세 — 고깃집 · 식당 (갤럭시탭형)

> 갤럭시탭에 앱을 설치한 사장님이 혼자 10분 안에 끝내는 5단계입니다. 공통 구조는 같고, 3 · 5단계에 업종 항목이 붙습니다.
> 테이블오더 매장은 **2-2 운영 방식**, **4-2 테이블 배치**, **4-3 태블릿 역할 지정**이 추가됩니다. 이 세팅은 **카운터 태블릿**에서 합니다.

## 1 사장님 시작

- 디자인: [`set-01-start`](../screenshots/set-01-start.png)
- 참고: docs/00 D2 (로그인 방식), D3 (기기 등록)

**구성**

- 휴대폰 번호 인증으로 사장님 계정 만들기 / 이미 계정이 있으면 로그인 후 이 태블릿을 추가 기기로 연결
- 준비물 안내: 사업자등록번호(카드 가맹), 블루투스 카드 리더, 영수증 프린터 — 나중에 넣어도 됨
- 왼쪽 5단계 진행 표시, 하단 "막히면 원격으로 도와드려요 [고객센터 번호]"

**예외**

- 인증번호 오류 · 시간 초과
- 이미 다른 매장에 연결된 기기

## 2 매장 정보

- 디자인: [`set-02-store`](../screenshots/set-02-store.png)
- 참고: core docs/08 5장

**구성**

- 가게 이름, **업종 선택**(식당 / 카페 / 버거 · 분식 / 기타)
- 로고 올리기(없으면 가게 이름 글자), 대표 사진 찍기(시작 화면 배경)
- 주문 방식(매장 · 포장), 손님 호출 방식
- 오른쪽 손님 시작 화면 미리보기 — 바꾸면 바로 반영

**예외**

- 업종 `기타`는 현재 미지원 → "곧 지원 예정" 안내 (결정 필요)
- 업종 변경 시 3단계 기본 분류가 바뀐다는 확인

## 2-2 운영 방식

- 디자인: [`set-02b-mode`](../screenshots/set-02b-mode.png)
- 참고: `docs/03-operation-modes.md`

**구성**

- 카드 3장: ① 카운터 키오스크 · ② 테이블오더 · 나갈 때 결제(`고깃집 추천`) · ③ 테이블오더 · 주문할 때 결제 — 각각 주문 위치 · 결제 시점 · 맞는 매장
- 옵션: ① 카운터 키오스크도 나갈 때 결제로(켬 → 테이블 번호 입력), ②에서 휴대폰 선결제 허용
- 안내: 나중에 바꿀 수 있고, 바꾸면 매장 태블릿이 모두 다시 시작. ①과 ②를 함께 쓰는 매장도 가능

**예외**

- ③ 선택 시 간편결제(PG) 가맹이 없으면 "간편결제 가맹 신청이 필요해요" 안내 후 ②로 시작 가능
- 업종 `식당`의 기본값은 ②

## 3 메뉴 등록

- 디자인: [`set-03-menu`](../screenshots/set-03-menu.png)
- 참고: 업종 `preset` · `setupExtras`

**구성**

- 왼쪽: 분류 칩(개수 표시) + 메뉴 목록, 오른쪽: 선택한 메뉴 편집
- 메뉴판 사진으로 한 번에 등록 (2차 — OCR · AI 인식, MVP는 버튼 숨김 또는 "준비 중")
- 사진 찍기, 메뉴 이름, 가격, 업종 전용 항목(아래 업종 표)
- 품절 표시, 주문서 출력 대상
- **식당 항목**: 단위(`1인분 250g`), 주문 단위(인분 단위 · 최소 2인분 · 더치페이 1인분씩 나누기), 함께 권하기(공깃밥 · 된장찌개 · 냉면)

**예외**

- 가격 0원 · 빈 이름 저장 불가
- 사진 없으면 업종 색 박스

## 4 결제 단말 · 프린터 연결

- 디자인: [`set-04-devices`](../screenshots/set-04-devices.png)
- 참고: core docs/03

**구성**

- ① 카드 결제: 사업자등록번호, 가맹 상태([VAN사]), 블루투스 카드 리더 연결 · 배터리, **테스트 결제 후 바로 취소**
- ② 영수증 프린터: 블루투스 / 와이파이 · LAN, 80mm ESC/POS, 테스트 출력
- ③ 주방 프린터: IP 자동 검색, 출력 분류, 다시 검색
- "주방 프린터가 없으면 영수증 프린터 하나로 주방 주문서까지 출력" 안내

**예외**

- 프린터 못 찾음 → IP 직접 입력
- 카드 리더 미연결 상태로 다음 진행 가능(손님 결제는 막힘)

## 4-2 테이블 배치 · 태블릿 연결 (② ③)

- 디자인: [`set-04b-tables`](../screenshots/set-04b-tables.png)

**구성**

- 구역 탭(홀 · 룸 · `+ 구역`), 구역별 테이블 수 − +, 번호 카드(연결됨 / 미연결)
- 번호를 누르면 이름 변경(예: 창가 3)
- 오른쪽: 테이블 태블릿 연결 QR + 6자리 연결 코드(10분 유효)

**예외**

- 테이블 수를 줄일 때 열린 계산서가 있는 번호는 줄일 수 없음
- 미연결 테이블이 있어도 다음 진행 가능 (현황판에 미연결 표시)

## 4-3 태블릿 역할 지정 (테이블 태블릿에서)

- 디자인: [`set-04c-pair`](../screenshots/set-04c-pair.png)
- 새 태블릿에 앱 설치 → 연결 QR 촬영 또는 코드 입력 → "이 태블릿은 어디에 두나요?"
- 역할: `카운터` · `테이블`(번호 선택) · `입구 키오스크`(① 화면)
- 이미 다른 태블릿이 쓰는 번호 → 바꿀지 확인
- 완료 → 테이블 태블릿은 잠금 모드로 대기 화면(`to-00-idle`)

## 5 키오스크 모드

- 디자인: [`set-05-kiosk`](../screenshots/set-05-kiosk.png)
- 참고: core docs/03 5장

**구성**

- 화면 방향(가로 추천 / 세로), 결제 방법(전체결제 · 더치페이, 더치페이 방식)
- 화면 잠금 · 복귀(앱 고정, 무입력 후 처음 화면 시간)
- 사장님 PIN 설정, 해제 방법 안내(화면 오른쪽 위 5번 탭 → PIN)
- 업종 전용 설정 (아래 업종 표)
- `키오스크 시작하기` → 잠금 진입 → 손님 시작 화면
- **식당 항목**: 식당 전용: 호출번호 `A-001`부터, 고기 최소 2인분, 주문서에 매장/포장 크게

**예외**

- PIN 4자리 미만 불가
- Device Owner 미설정이면 화면 고정 모드로 시작하고 안내

## 수용 시나리오

- [ ] 새 태블릿에서 1→5단계를 마치고 `키오스크 시작하기` → 손님 시작 화면
- [ ] 2단계에서 업종 `식당` 선택 → 3단계 기본 분류가 고기 · 식사 · 찌개 · 탕 · 주류 · 음료
- [ ] 4단계 테스트 결제(즉시 취소) · 테스트 출력 성공
- [ ] 5단계 PIN 설정 후 화면 오른쪽 위 5번 탭 → PIN → 세팅 화면 복귀
- [ ] 2-2에서 ② 선택 → 4-2에서 홀 12 · 룸 2 등록 → 연결 코드 표시
- [ ] 새 태블릿에서 코드 입력 → `테이블` · 12번 → 대기 화면 "12번 테이블", 카운터 4-2 화면에 12번 `연결됨`
- [ ] 같은 12번을 다른 태블릿에서 고르면 바꿀지 확인
- [ ] 열린 계산서가 있는 12번이 포함되면 테이블 수를 11로 줄일 수 없음
